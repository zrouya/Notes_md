
Les comptes Azure s'articulent autour de la notion de **Azure Account**.

Chaque Azure Account est lié :
- A des [[Azure Subscription|Subscriptions]] Azure, pour les notions de facturation
- A des [[Resource Azure|ressources Azure]] (services), regroupées en [[Resource group Azure|groupes de ressources]] (applications).
- A un [[Microsoft Entra ID (ex. Azure Active Directory)|compte Entra ID]] (anciennement Azure Active directory), propriétaire du compte Azure (voir les [[Rôles Azure RBAC (Role Based Access Control)|rôles]] Azure)
