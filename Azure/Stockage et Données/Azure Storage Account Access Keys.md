
Après la création d'une ressource [[Azure Storage Accounts|Azure storage account]], 2 clés d'accès sont créées, et sont consultables dans la section "Security + Networking / Access Keys".

Elles permettent d'accéder à **l'ensemble des services et ressources** du storage account.
Pour une gestion plus fine des autorisations, il est possible de configurer des [[Azure Storage Shared Access Signatures (SAS)|shared access signatures]].

![[Pasted image 20240811154930.png]]

Les connection strings permettent d'accéder aux ressources du Storage Account via des applications clientes, comme **Azure Storage Explorer**.
