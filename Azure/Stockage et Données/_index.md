# Stockage et Données

Services Azure de stockage d'objets et de données : Blob Storage, Storage Accounts, bases NoSQL (Cosmos DB) et relationnelles (SQL Database).

## Notes

- [[Azure Storage Accounts]] — ressource offrant Blob, Table et Queue storage
- [[Azure Storage Accounts Authorization]] — modes de gestion des autorisations d'un storage account
- [[Azure Storage Account Access Keys]] — clés d'accès globales à un storage account
- [[Azure Storage Shared Access Signatures (SAS)]] — URLs à droits d'accès restreints pour un blob ou container
- [[Azure Blob Storage]] — service de stockage de fichiers binaires (blobs) regroupés en containers
- [[Azure Blob Storage - DotNet applications]] — utilisation du package Azure.Storage.Blobs en .NET
- [[Azure Blob Storage Access Tier]] — niveaux tarifaires de stockage selon la fréquence d'accès
- [[Azure Cosmos DB]] — service distribué de bases de données multi-modèles
- [[Azure Cosmos DB - NoSql API]] — API NoSql (JSON, requêtes SQL) de Cosmos DB
- [[Azure Cosmos DB - Table API]] — API Table Storage de Cosmos DB (colonnes primitives)
- [[Azure SQL Database]] — service PaaS de bases de données SQL Server
- [[DTU (Database Transaction Unit) SQL Azure]] — unité de mesure combinée (calcul, mémoire, I/O) pour Azure SQL
- [[SQL elastic pool Azure]] — pool de ressources partagées entre plusieurs bases Azure SQL
- [[vCore Azure]] — cœurs virtuels de calcul disponibles pour Azure SQL
