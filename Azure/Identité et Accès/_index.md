# Identité et Accès

Gestion des identités, des autorisations et de la sécurité réseau sur Azure : IAM, RBAC, Managed Identities, Entra ID et Key Vault.

## Notes

- [[Azure Access Control (IAM - Identity and access management)]] — service de gestion des utilisateurs et autorisations
- [[Rôles Azure RBAC (Role Based Access Control)]] — rôles Azure basés sur le contrôle d'accès
- [[Azure Role Assignment]] — association d'un security principal à un rôle Azure
- [[Azure Managed Identities]] — identités gérées pour l'authentification des ressources Azure sans credentials
- [[Azure Application Object]] — artefact d'autorisations flexibles associé à une application (service principal)
- [[Microsoft Entra ID (ex. Azure Active Directory)]] — référentiel d'identités centralisé pour les services Microsoft
- [[Microsoft Graph]] — API Azure d'accès aux utilisateurs d'un tenant Entra ID
- [[Azure Key Vault]] — stockage sécurisé de secrets, clés de cryptage et certificats
- [[Network security group (NSG) Azure]] — règles de filtrage du trafic réseau des ressources Azure
- [[Bastion]] — service Azure de connexion sécurisée aux VM sans exposition RDP/SSH directe
