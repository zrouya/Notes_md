# Conteneurs et Functions

Services Azure de conteneurisation (Container Apps, Instances, Registry, AKS) et de calcul serverless (Azure Functions).

## Notes

- [[Azure Container App]] — conteneurs serverless reposant sur Kubernetes, sans gestion d'infrastructure
- [[Azure Container Group]] — regroupement de container instances partageant le même hôte
- [[Azure Container Instances]] — déploiement simple de conteneurs Docker sans orchestration
- [[Azure Container Registry]] — registry d'images Docker hébergé sur Azure
- [[Azure Kubernetes Service]] — déploiement de clusters Kubernetes managés (AKS)
- [[Azure Function App]] — ressource PaaS hébergeant des fonctions serverless
- [[Azure Functions]] — fonctions individuelles au sein d'une Function App, avec triggers
- [[HTTP Trigger Azure Function]] — fonction Azure déclenchée par requête HTTP(S)
