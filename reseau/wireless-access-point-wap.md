# Wireless Access Point (WAP)

Un WAP (Wireless Access Point) est l'équivalent pour les réseaux sans fils du [[Switch réseau|switch]] pour les réseaux câblés. Il intervient, comme les switches, au [[Couche de liaison de données du modèle OSI|niveau 2]] du modèle OSI.

## Précision

**Note :** Il ne s'agit pas d'un [[Routeurs réseaux|routeur réseau]].
