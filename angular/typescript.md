# TypeScript

TypeScript est un sur-ensemble de JavaScript développé par Microsoft, qui ajoute des types statiques et d'autres fonctionnalités au langage. Il constitue le langage principal de développement des applications [[angular-overview|Angular]].

## Caractéristiques principales

- Typage statique optionnel (interfaces, types, generics).
- Compilation (transpilation) vers du JavaScript standard.
- Support des [[decorateurs-en-typescript|décorateurs]], massivement utilisés par Angular pour les métadonnées de classes.
