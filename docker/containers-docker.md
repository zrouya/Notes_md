# Containers Docker

Un conteneur Docker peut être vu comme un **groupe de processus** qui s'exécute **de manière isolée** au sein de l'hôte. L'isolation des conteneurs est basée sur des fonctionnalités du kernel Linux qui permettent la virtualisation légère : les [[namespaces-linux|namespaces]], et les [[control-groups-linux|Cgroups]].
