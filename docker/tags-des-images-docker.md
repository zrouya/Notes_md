# Tags des images Docker

Un tag d'image Docker est un **pointeur** vers un **commit spécifique** de cette image, au sein d'un [[docker-repository|Docker repository]].

Pour modifier un tag : ``docker image tag SOURCE_IMAGE[:tag] TARGET_IMAGE[:tag]`` (si les tags, optionnels, ne sont pas renseignés, il s'agit du **tag par défaut : latest**).
