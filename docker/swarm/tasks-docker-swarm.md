# Tasks Docker Swarm

Les tâches Docker Swarm sont des **instances** d'un [[services-docker-swarm|service]] qui sont exécutées sur les nœuds [[workers-swarm|Worker]] ou [[manager-swarm|Manager]] selon les besoins. Une tâche Docker Swarm donne lieu à la **création d'un [[containers-docker|conteneur]]** par un worker. Il s'agit de **l'unité atomique** de **planification** d'un cluster Swarm.
