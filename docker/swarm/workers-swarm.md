# Workers Swarm

Les workers Swarm sont un type de [[noeuds-swarm|nœuds]] qui assure l'exécution des [[tasks-docker-swarm|tâches]] du cluster. Ils ont pour fonction de gérer les [[containers-docker|conteneurs]] implémentant ces tâches.
