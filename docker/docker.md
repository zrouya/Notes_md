# Docker

Docker est un gestionnaire de conteneurs **portable**, **cross-platform**, et **agnostique au langage**. Le workflow implémenté par Docker est [[build-des-images-docker|build]], [[docker-registry|ship]], [[execution-des-conteneurs-docker|run]], sur la base des [[images-docker|images]] Docker.

Pour des questions de bonnes pratiques d'architecture, voir :
