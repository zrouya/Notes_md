# Azure Entra (anciennement Azure Active Directory)

Azure Entra (anciennement Azure Active Directory) est un **fournisseur d'identités** du cloud Azure. Avec chaque compte Azure est associé un Azure Entra, à partir duquel il est possible de **créer des utilisateurs**, des **groupes** d'utilisateurs, et de les **rattacher aux ressources** et groupes de ressources (applications) du compte Azure associé.
