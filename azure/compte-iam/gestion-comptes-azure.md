# Gestion des comptes Azure

Les comptes Azure s'articulent autour de la notion d'**Azure Account**.

## Liens d'un Azure Account

Chaque Azure Account est lié :
- À des Subscriptions Azure, pour les notions de facturation
- À des [[resource-azure|ressources Azure]] (services), regroupées en [[resource-group-azure|groupes de ressources]] (applications)
- À un [[azure-entra|active directory]], pour la gestion des comptes utilisateurs
