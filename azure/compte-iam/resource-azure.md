# Resource Azure

Une ressource Azure désigne tout **service** qui peut être utilisé dans l'écosystème **Azure**. Par exemple :
- Machines virtuelles
- Azure App Service
- Azure Kubernetes Service
- Azure Blob Storage
- ...

## Rattachement

Toute ressource Azure doit faire partie d'une [[azure-subscription|Azure Subscription]], et doit faire partie d'un [[resource-group-azure|Resource group Azure]].
