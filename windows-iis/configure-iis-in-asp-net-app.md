# Configuration IIS pour une application ASP.NET

Pour configurer un serveur [[internet-information-service-iis|IIS]] afin qu'il serve une application ASP.NET, on utilise le fichier `web.config`.

## Configuration

- Le fichier `web.config`, placé à la racine de l'application, définit les paramètres du serveur IIS pour cette application (module ASP.NET Core, variables d'environnement, redirections, etc.).
