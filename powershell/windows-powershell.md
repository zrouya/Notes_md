# Windows PowerShell

Windows PowerShell est un [[types-de-shell|type de shell]] conçu pour les systèmes Windows, combinant un shell de commande avec un langage de script basé sur le framework .NET. Contrairement aux shells UNIX/Linux qui manipulent du texte, PowerShell manipule des objets .NET.

## Objets .NET et cmdlets

- Les commandes, appelées [[cmdlets-powershell|cmdlets]], manipulent et retournent des objets .NET, pas seulement des chaînes de texte.
- Cela permet une interaction plus riche avec le système et les applications qu'un shell texte classique.

## Automatisation et scripting

- PowerShell est particulièrement puissant pour l'automatisation de tâches administratives Windows : gestion des utilisateurs, registre Windows, gestion des services.
- Il permet d'écrire des scripts complexes interagissant avec le système d'exploitation et les applications Windows à un niveau détaillé.

## Interopérabilité

- PowerShell Core est une version cross-platform, fonctionnant aussi sur Linux et macOS.

## Intégration avec les technologies Microsoft

- Étroitement intégré avec les serveurs Windows, SQL Server et d'autres applications d'entreprise, ce qui le rend particulièrement utile en environnement d'entreprise.
