# Adressage

Adressage IP et MAC : versions d'IP, sous-réseaux, adresses virtuelles, distinction public/privé et traduction d'adresses.

## Notes

- [[Adresse IP]] — identifiant logique d'un hôte sur un réseau
- [[IPv4]] — version 4 du protocole d'adressage IP
- [[IPv6]] — version 6 du protocole d'adressage IP
- [[Adresses MAC]] — identifiant physique d'une interface réseau
- [[Adresses IP Vituelles (VIP)]] — adresse IP partagée non liée à une interface physique unique
- [[Masque de sous-réseau]] — délimitation de la partie réseau/hôte d'une adresse IP
- [[Sous-réseau]] — subdivision logique d'un réseau IP
- [[Clients Publics et Privés]] — distinction entre adressage public et privé
- [[NAT (Network Address Translation)]] — traduction d'adresses privées en adresses publiques
