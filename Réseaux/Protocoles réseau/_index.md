# Protocoles réseau

Les protocoles concrets utilisés sur un réseau : transport (TCP/UDP), résolution d'adresses, diagnostic, et protocoles applicatifs courants (HTTP, DNS, FTP, DHCP).

## Notes

- [[Protocole IP (Internet Protocol)]] — protocole d'adressage et de routage de la couche réseau
- [[Protocole TCP]] — transport fiable et connecté
- [[Cession TCP]] — établissement/fermeture d'une session TCP
- [[Protocole UDP]] — transport non connecté, sans garantie de livraison
- [[Ports réseaux]] — identification des services via les ports TCP/UDP
- [[Adress Resolution Protocol (ARP)]] — résolution d'une adresse IP en adresse MAC
- [[Internet Control Message Procotol (ICMP)]] — messages de contrôle et de diagnostic réseau
- [[Types de messages ICMP]] — catalogue des types de messages ICMP
- [[HTTP(S)]] — protocole applicatif du web, sécurisé ou non
- [[Requêtes HTTP]] — structure et méthodes des requêtes HTTP
- [[File Transfert Protocol (FTP)]] — transfert de fichiers entre hôtes
- [[Domain Name System (DNS)]] — résolution de noms de domaine en adresses IP
- [[DNS record]] — types d'enregistrements DNS
- [[Round Robin DNS]] — répartition de charge via des réponses DNS multiples
- [[Serveur DHCP]] — attribution dynamique d'adresses IP
