# Terminal et Shell

Le terminal est une interface utilisateur en ligne de commande (CLI) permettant d'interagir avec le système d'exploitation via des commandes textuelles. Le shell est le programme qui interprète ces commandes ; il existe plusieurs [[types-de-shell|types de shell]], dont Bash.

## Terminal

- Aussi appelé émulateur de terminal ou console.
- Utilisé pour exécuter des programmes, gérer les fichiers du système et effectuer des tâches administratives.

## Shell et Bash

- Le shell interprète les commandes entrées dans le terminal (Bourne Shell, C Shell, Korn Shell, etc.).
- Bash (Bourne Again Shell) est une amélioration du Bourne Shell original, largement utilisé sur les systèmes UNIX (Linux, macOS).
- Bash supporte des fonctionnalités avancées : scripts, alias de commandes, complétion de commandes.

## Fonctionnalités et utilisations

- Les scripts de shell automatisent les tâches répétitives (boucles, conditions, fonctions).
- La gestion des fichiers et des processus est une partie essentielle du travail avec le shell.

## Permissions et sécurité

- Sous UNIX, chaque fichier a des permissions associées (lecture, écriture, exécution).
- Le shell permet de modifier ces permissions et de gérer les droits d'accès.

## Variables d'environnement

- Stockent des informations utilisées par le système ou des applications (chemins, paramètres de configuration).

## Commandes courantes

- `ls` (lister les fichiers), `cd` (changer de répertoire), `cp` (copier), `mv` (déplacer/renommer), `rm` (supprimer).

## Avantages et limitations

- Avantages : contrôle précis et puissant, opérations rapides et automatisées.
- Limitations : courbe d'apprentissage, moins intuitif que les interfaces graphiques.
