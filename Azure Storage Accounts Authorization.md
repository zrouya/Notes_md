
La gestion des autorisations au sein d'un [[Azure Storage Accounts|Azure Storage account]]  peut se configurer de plusieurs manières : 
- **Anonymous Access** pour donner accès à un **Container** [[Azure Blob Storage|Blob storage]].
- **[[Azure Storage Account Access Keys|Access Keys]]** pour accéder à tous les services d'un **Storage Account**.
- **[[Azure Storage Shared Access Signatures (SAS)|Shared Access Signatures]]** pour configurer des **restrictions d'accès**.
