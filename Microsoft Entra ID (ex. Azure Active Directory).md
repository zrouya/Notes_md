
Microsoft  Entra ID est un **identifiant** de **locataire (tenant)**, qui représente un **référentiel d'identités** pour l'**ensemble des services Microsoft** (Azure, Active Directory, Microsoft 365, Teams,...).
Ce locataire assure les services d'**authentification** et d'**autorisation**.

Il s'agit d'une **évolution** du service **Azure Active Directory** (gestion des utilisateurs dans le contexte du [[Azure|cloud Azure]]), pour permettre une **gestion centralisée** au travers de tous les services Microsoft (ex : Active Directory, pour les infrastructures on-premise, peut maintenant s'interfacer avec Entra ID, pour une **gestion unifiée** des infrastructures **hybrides**)

Entra ID possède son **référentiel** de **rôles** spécifique (centralisé).
Le référentiel Entra ID peut être managé via le portail Azure, et les rôles spécifiques aux services Azure sont gérés au niveau du [[Azure Access Control (IAM - Identity and access management)]].
